# CareFusion (BD)

> CareFusion is a medical technology brand acquired by BD (Becton, Dickinson and Company)
> in 2015, best known for the Alaris infusion system and the Pyxis automated dispensing
> line. CareFusion publishes NO public developer API, NO OpenAPI/AsyncAPI/GraphQL/WSDL
> contract, NO SDK and NO developer portal. Its products interoperate with hospital EMR and
> pharmacy systems over HL7 v2 interfaces that BD interface-engineering teams configure per
> site under a customer contract.

## What exists

- Alaris Infusion Interoperability — EMR-to-pump order transmission for BD Alaris
  large-volume, syringe and PCA modules, with infusion status returned to the EMR and the
  Alaris Guardrails drug library as the clinical decision-support layer. Product page:
  https://www.bd.com/en-us/products-and-solutions/products/product-families/bd-alaris-emr-interoperability
- Pyxis Automated Dispensing Integration — BD Pyxis ES cabinets synchronised with pharmacy
  information systems and EMRs over HL7 v2 (ADT, ORM, RDE, RDS) message families.
  Brand page: https://www.bd.com/en-us/products-and-solutions/products/product-brands/pyxis

## What does NOT exist (measured, not assumed)

- No OpenAPI or Swagger. https://www.bd.com/openapi.json and /swagger.json both return 404
  to a browser-class request.
- No developer portal, API reference, getting-started guide, sandbox, CLI, SDK, Postman
  collection, MCP server or A2A agent card. The bd.com/en-us sitemap holds 1,382 URLs and
  none of them is a developer or API page; none of them contains the string "carefusion".
- No /.well-known/ document on any bd.com or carefusion.com host. See
  well-known/carefusion-well-known.yml for the full per-host probe record.
- No published plans, pricing or rate limits. Commercial terms are quoted per hospital.
- No first-party package in npm, PyPI, RubyGems or crates.io. github.com/CareFusion is an
  empty organisation with zero public repositories and no attribution to BD.

## Where the integration surface actually lives

The HL7 v2 interface specification for Alaris and Pyxis is delivered to contracted customers,
not published. The surviving CareFusion-domain surface is a login-only portal:
https://rsscp.carefusion.com/ ("BD - RSS Customer Portal"), an AngularJS single-page
application that answers HTTP 200 with the same 1,940-byte shell for every path.
